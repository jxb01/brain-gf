# brain_gf — 无梯度自适应系统（纯 NumPy）

冻结的手工算子特征库 + concat 读出 + 在线误差写入（NLMS）/ 闭式最小二乘。
**全程没有反向传播、没有 autograd、没有优化器状态。** 所有"学习"都是一次误差外积写进读出矩阵。

这个仓库是一串**可复现的否证实验**：它记录了什么能工作、什么被数据打掉，以及为什么。
如果你在找"会自己长大的类脑树"，结论是它在这套框架里不成立；如果你在找
"极低算力、可在线适应、能被完整解释的随机特征核机器"，这里有可用的实现和测量。

---

## 1. 它是什么 / 不是什么

**是**
- 一个核机器：随机特征映射（冻结）+ 线性读出（只有一个矩阵在学）。
- 一个在线学习器：单遍流式，逐样本更新，可部署到无 GPU 环境。
- 一套对照实验：与岭回归上限、储备池（ESN）、线性 AR、离线批处理对照。

**不是**
- 不是梯度下降的替代品。离线、大批量、固定分布下，BP 训练的模型更强。
- 不是"会生长的树"。结构动态（路由 / 生长 / 修剪 / 共识汇聚）在本仓库全部实测为负收益。
- 不是通用世界模型。它在低维、平滑、或马尔可夫型目标上很强；在需要长记忆的部分观测系统上会掉。

## 2. 核心结论

### 2.1 有效成分（四条，全部有对照）

| 机制 | 效果 |
|---|---|
| **concat 读出**（不是求和 / 不是加权平均） | 同特征下 R² 高 0.4~0.5 |
| **滞后窗输入**（混沌任务） | 5 步预测 0.667 → 0.799（单项最大收益） |
| **手工算子库**（替代随机 GRU 柱） | 同任务 0.560 → 0.683，且快 3 倍 |
| **NLMS 逐特征在线标准化** | 不做则发散到 −1630，做了 0.901 |

### 2.2 被证伪的机制（同一个根因的七种表现）

| 机制 | 实测 | 根因 |
|---|---|---|
| 动态 top-k 路由 | −0.16 R² | 每特征出现率 k/n，读出样本预算被切碎 |
| 激素调节 k | −0.05 ~ −0.25 | 同上 |
| 结构生长 / 修剪 | ±0.005（噪声内） | 加列不加样本，净收益被摊薄抵消 |
| 生存分数（credit 剪枝） | corr(激活,生存) = −0.85 | 判据与自己该奖励的东西反相关 |
| 共识 / 聚类汇聚 | −0.2 起 | 加权和仍在凸包内，容量不增 |
| dopamine 更新路由矩阵 | +0.004 | 标量且恒非正，不含方向信息 |
| 遗忘衰减 decay | −0.03 ~ −0.13 | NLMS 本来就会重新拟合，衰减只加偏置 |

### 2.3 两个数学事实（可以用来省掉大量试错）

1. **加法树 ≡ concat 读出**
   $\sum_j \phi_j(x) w_j = [\phi_1(x),\dots,\phi_n(x)]\cdot[w_1,\dots,w_n]$
   所以"多分支各自预测再相加"不需要任何新机制，concat 就是它。只有**门控**才会带来新函数类，
   而门控在无梯度设定下无法学到"谁准"。

2. **逐支拟合自己的残差（backfitting）在本设计上发散**
   块 Gauss-Seidel 的迭代谱半径实测 **ρ = 6.911**（必须 < 1），所以并行 / 阻尼 / 顺序 / 加下限
   四种写法全部炸掉。可收敛的写法是**按序 deflation**（每支只拟合冻结前缀的残差），
   实测 0.960（concat 单读出 0.986）。

## 3. 快速开始

```bash
pip install -r brain_gf/requirements.txt     # numpy (matplotlib 可选，用于出图)

# 主基准：A(sine) -> B(square) -> A，含恢复速度与单步耗时
python -m brain_gf.bench_ns --outdir runs/brain_gf

# 复现结论摘要（约 1 分钟）
python -m brain_gf.report
```

产物：`results.json`（分段 R²、恢复步数、µs/step、参数量）、`rolling.csv`、`fig_ns.png`。

## 4. API

```python
import numpy as np
from brain_gf.nest_ops import OpBrain

brain = OpBrain(layers=1, in_dim=8, hid=8, n_columns=128, topk=16,
                out_dim=8, agg="concat", combine="concat", static_mask=True)

for x, y in stream:                       # 单遍在线
    pred = brain.step(x, y)               # 预测 + 物理写入，一步完成

# 也可分开：predict 只读，step 才写
pred, feats = brain.forward(x)
```

关键参数：

| 参数 | 含义 | 建议 |
|---|---|---|
| `combine` | 柱内 4 个算子如何合并 | `"concat"`（`"mean"` 会掉 0.2） |
| `agg` | 列间如何汇聚 | `"concat"` |
| `static_mask` | 固定选列 vs 每步动态选 | `True`（动态掉 0.16） |
| `topk` | 用多少列 | 8~16；更大在样本不足时掉分 |
| `dead_err` | 误差死区（低于则跳过写入） | `1.0 × rms(e)`，启动期设 0 |

## 6. 已知边界（写报告时要一起写）

1. **样本预算决定上限**：一遍流式时特征数应 ≲ N/10；512 特征在大 N 下逼近岭上限的 97%，一遍做不到。
2. **长记忆任务是弱项**：库里只有 `diff`/`cumsum` 两个算子带状态，其余逐帧。部分观测混沌里
   靠"喂滞后窗"补，而不是靠模型自己记。
3. **在线更新比批处理低约 0.1 R²**：0.901 vs 岭 0.996（Lorenz 全状态）。
4. **所有"结构动态"结论都在低维合成/混沌流上得到**；更高维、非平稳真实数据可能改写，
   但本文档里的七个负结果是可复现的。
